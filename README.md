# Peper24 App

Peper24 英语口语陪练的 Web 前端原型。当前版本用于确认完整产品流程与界面交互，数据保存在浏览器本地，尚未连接真实服务端。

## 技术栈

- React 19 + TypeScript + Vite
- React Router
- Zustand（本地持久化）
- TanStack Query（为后续服务端请求预留）
- Lucide React

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建与静态检查：

```bash
pnpm build
pnpm lint
```

## 演示流程

1. 首页选择注册。
2. 输入任意合法邮箱和不少于 6 位的密码。
3. 邮箱验证码固定为 `123456`。
4. 完成昵称和 A1-C2 英语水平设置。
5. 选择话题进入聊天，也可从“学习”和“我的”进入词汇、复习、记忆及设置页面。

聊天页支持浏览器录音授权与录音，但当前语音识别结果为本地模拟；AI 回复同样采用本地流式模拟。刷新页面后，用户资料、会话、词汇和复习进度仍会保留在浏览器 `localStorage` 中。

## 当前边界

- 固定一个 AI 陪练角色。
- 同一语法错误第二次出现时提醒一次，之后保持静默。
- 复习题采用“看英文选中文”，评分由答题结果自动计算。
- 当前仅实现一个产品版本，不包含免费版或 Max 版分层。
- 真实账号、AI、ASR、TTS、OSS 音频保存和 30 天清理任务将在服务端阶段接入。
